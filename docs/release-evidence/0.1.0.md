Date: **13 November 2026**  
Release: [`v0.1.0`](https://github.com/artemidius/Le-Rust/releases/tag/v0.1.0)

- Six public operations: list/retrieve models, complete/stream chat, and complete/stream FIM.
- Native tool payloads, explicit tool-result continuation, JSON/JSON Schema response formats, predicted output, and bounded stream collection.
- Rust 1.88 minimum; default rustls transport; optional metadata-only tracing.
- Official OpenAPI source: `https://docs.mistral.ai/openapi.yaml`.
- Reviewed SHA-256: `7b344504336785172c86cd826ce4b1cbfd12be228a8432cf046b2b8fdafacf72`.
- The exact-digest and covered-surface drift check both passed on 2026-11-13.

The crates.io API returned `404` for the exact `le-rust` name and an exact-name Cargo search returned no result on 2026-11-13. This establishes availability at check time, not ownership until publication.

## Deterministic validation

The release candidate passed locally on macOS and in the GitHub pull-request matrix:

```text
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features
cargo test --doc --all-features
RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --all-features
cargo +1.88.0 check --all-targets --all-features
cargo +1.88.0 test --all-features
python3 -m unittest scripts/test_check_openapi.py
cargo package
bash scripts/test-package-consumer.sh target/package/le-rust-0.1.0.crate
cargo publish --dry-run
```

Local Rust results: 20 library tests, 16 integration tests across two binaries, and 2 doctests passed. The extracted package contained 35 files, was 229.4 KiB unpacked and 59.5 KiB compressed, compiled successfully, and passed the independent consumer workflow.

The package consumer uses only public APIs. Against its local mock it performs model list/retrieve, chat streaming and indexed tool-call collection, explicit tool-result continuation, JSON Schema response parsing, FIM complete, and FIM streaming.

## Hosted validation

- Pull request and self-review: [#3](https://github.com/artemidius/Le-Rust/pull/3).
- CI matrix: Ubuntu 24.04, macOS 15 Intel, Windows current, Rust stable, and Rust 1.88.
- API drift workflow: classified the current upstream source as `exact_match` and uploaded its JSON report.

No `MISTRAL_API_KEY` was available to this release process, so authenticated provider compatibility was **not run**. The manual `Live Mistral compatibility` workflow is configured for account-selected chat and Codestral models and covers every supported operation plus tools and structured output. The release does not present mock-server success as hosted-service evidence.

## Distribution decision

`cargo publish --dry-run` completed through package verification and stopped before upload as expected. No crates.io token was available, so registry publication was not attempted. The Git tag and GitHub release provide an immutable source dependency; registry publication remains the separate maintainer action documented in the release policy.
